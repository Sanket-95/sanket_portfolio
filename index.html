Advanced Automatic Bale Handling System

Project Overview

Led the migration and upgrade of a sophisticated bale handling system originally developed in 1994 by Autefa, a German company. This project, designed to enhance operational efficiency in the management of over 60,000 bales, integrates both manual and automated warehouse operations at Reliance Industries Limited, Hazira.

Key Responsibilities

  • Oversaw the migration from a DOS-based legacy system to a modern Oracle database environment, ensuring seamless data handling and increased system performance.
  • Implemented Oracle Apex for robust GUI development, improving user interaction with the front-end application.
  • Coordinated with multiple server setups to facilitate diverse operational needs across different segments of the production line.
  • Developed Linux-based shell scripts as a secondary resource to enhance system reliability and backup processes.

Achievements

  • Successfully enhanced system flexibility, allowing for precise management of production lines and inventory.
  • Improved system response times and accuracy, significantly boosting overall productivity and operational efficiency.
  • Developed an advanced user interface, markedly enhancing user experience compared to the older DOS-based system.

Technologies Used

Oracle Database, Oracle Apex, Linux Shell Scripting, Ingres Database (legacy), C language warehouse server program, JavaScript

Project Timeline

November 2023 - July 2024

Location

Onsite and Offsite at Reliance PSF Warehouse, Hazira, Gujarat

Cipla Report Application

Project Overview

Developed and implemented a comprehensive Report Application for a newly commissioned 15K + 10K + 12K pressure tank system used in the production of sensitive pharmaceutical drugs. The system integrates process data from the WINCC server and follows 24 CFR compliant reporting standards to ensure traceability and regulatory accuracy.

The application was designed to log, monitor, and audit every critical stage of medicine manufacturing — from raw material input to final product output. A total of 40+ analytical and audit reports were developed to support process validation, equipment performance monitoring, and product quality assurance.

Key Highlights

  • Built using .NET with MVVM architecture for scalable and maintainable design.
  • Integrated SQL linked WINCC server for seamless real-time data fetching.
  • Delivered 24 CFR compliant reports supporting audit and regulatory needs.
  • Enhanced process transparency and quality inspection through detailed reporting.

Technologies Used

.NET (MVVM Architecture), SQL Server, WINCC Linked Server

Project Duration

August – September 2023

Client

Cipla Ltd., Goa (Onsite)

AMC Support System

Project Overview

Developed a comprehensive system to provide end-to-end support to clients and engineer support through generating tickets. This innovative solution uses WhatsApp chat integration to streamline communication and support processes.

System Features

  • WhatsApp bot developed using Node.js and Webhook for real-time communication
  • Automated notifications sent on WhatsApp using Python service
  • Comprehensive AMC dashboard to control and manage support operations
  • Website developed using React, Node.js, and MySQL
  • Fully authentication-based system providing flexibility to manage clients and engineers

Key Benefits

  • Streamlined client support process with automated ticket generation
  • Real-time notifications to engineers for prompt response
  • Centralized dashboard for monitoring and managing all support activities
  • Secure authentication system for different user roles

Technologies Used

Node.js, React, MySQL, Python, Webhooks, WhatsApp Business API
